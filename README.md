# Genesis.dev – Landing en React

Landing de servicios hecha con React y Vite.

## Estructura

- `src/data.js` → tus datos (contacto, servicios, precios, preguntas). **Aquí cambias textos y precios.**
- `src/styles.css` → todo el diseño y los colores.
- `src/components/` → un archivo por sección (Hero, Services, Pricing, Faq…).
- `src/App.jsx` → junta las secciones en orden.
- `.github/workflows/deploy.yml` → publica la página solo con cada `git push`.

## Comandos

```
npm install      # instala lo necesario (solo la primera vez)
npm run dev      # ver la página mientras editas
npm run build    # genera la versión final en /dist
```
